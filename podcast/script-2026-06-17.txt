Dejen de usar JWT para sesiones en navegador
Un gist de GitHub del usuario samsch argumenta que los JSON Web Tokens (JWT) no deberían usarse para sesiones de usuario en navegadores debido a fallos de seguridad, lo que generó un amplio debate en Hacker News sobre usos apropiados y alternativas. Reducir swappiness a 10 mejora respuesta en servidor casero con 8GB RAM
Un usuario con un servidor doméstico de 8GB de RAM reemplazó el archivo de swap de 4GB por uno de 8GB y redujo vm.swappiness de 60 a 10, disminuyendo el uso de swap de 3.7GB a 280MB y mejorando la respuesta del sistema. Este ajuste práctico muestra cómo un simple cambio de parámetro del kernel puede reducir el desgaste del SSD y mejorar el rendimiento de contenedores Docker en servidores con memoria limitada, ofreciendo una optimización sin costo para la comunidad de autoalojamiento. El sistema ejecuta Ubuntu Server 24.04 LTS con un Intel Core i5-8250U y SSD NVMe; tras reducir swappiness a 10, el uso de RAM se mantiene en ~93% (7.3GB) pero el swap bajó a 280MB, y el usuario se mantiene precavido ante riesgos del OOM killer bajo alta presión de memoria.
