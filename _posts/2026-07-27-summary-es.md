## [Kimi-K3: modelo mxFP4 de 3T parámetros en HuggingFace](https://huggingface.co/moonshotai/Kimi-K3) ⭐️ 8.0/10

El 27 de julio de 2025, Moonshot AI lanzó el modelo Kimi-K3 en HuggingFace. Se trata de un modelo de lenguaje de 3 billones de parámetros que utiliza cuantización nativa mxFP4. Este lanzamiento demuestra la viabilidad de servir modelos de 3 billones de parámetros y probablemente reducirá los costos de inferencia para modelos grandes, beneficiando a la comunidad de IA. **Contexto**: MXFP4 es un formato de coma flotante de 4 bits con escalado compartido a nivel de bloque, diseñado para implementación eficiente en hardware y menor uso de memoria. Moonshot AI es una empresa de inteligencia artificial con sede en Pekín, conocida por desarrollar el asistente Kimi. El lanzamiento de un modelo abierto tan grande resalta la creciente tendencia de laboratorios chinos de IA a contribuir al ecosistema de código abierto.

## [El mercado de relevos impulsa la reventa y el fraude de tokens LLM](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 8.0/10

Una nueva investigación de Matt Lenhard revela un mercado próspero donde se revenden tokens de LLM a precios rebajados mediante el abuso de pruebas gratuitas, bots de soporte no protegidos y tarjetas de crédito robadas. Este mercado expone vulnerabilidades de seguridad significativas en los ecosistemas de API de LLM, donde los estafadores pueden lucrarse con credenciales robadas o abusadas, y destaca la necesidad urgente de mejores límites de gasto y monitoreo por parte de los proveedores de API. Los revendedores utilizan herramientas proxy de código abierto como one-api y su bifurcación new-api para agrupar credenciales de API y ofrecer descuentos de hasta el 90 % sobre los precios oficiales, dirigidos a usuarios en China y a quienes necesitan evitar restricciones geográficas.

rss · Simon Willison · jul 26, 19:30

**Contexto**: Las API de modelos de lenguaje grandes generalmente se cobran por token y el acceso se controla mediante claves de API. Los revendedores crean capas proxy que agregan credenciales de fuentes dudosas, como tarjetas de crédito robadas o abuso de pruebas gratuitas, para ofrecer precios significativamente más bajos. El software proxy de API de código abierto como one-api y su bifurcación new-api facilitan esto al permitir el balanceo de carga entre múltiples claves y proporcionar una interfaz compatible con OpenAI.

## [Scriptc de Vercel: Compilador de TypeScript a Nativo Desata Debate](https://github.com/vercel-labs/scriptc) ⭐️ 7.0/10

Vercel Labs lanzó Scriptc, un compilador de código abierto que convierte código TypeScript directamente en ejecutables nativos sin necesidad de un runtime de JavaScript. Scriptc podría permitir aplicaciones más pequeñas y rápidas al eliminar la dependencia de Node.js, pero la comunidad cuestiona su originalidad y mantenimiento a largo plazo. El compilador está diseñado para TypeScript estático y ofrece compatibilidad byte a byte con Node para construcciones compiladas, pero no soporta todo el ecosistema npm, requiriendo un motor JavaScript para muchos paquetes.

hackernews · maxloh · jul 26, 22:46 · [Discusión](https://news.ycombinator.com/item?id=49063175)

**Contexto**: TypeScript es un superconjunto tipado de JavaScript que normalmente se compila a JavaScript y se ejecuta en un motor JavaScript como Node.js o un navegador. La compilación nativa de TypeScript es un área de desarrollo activo, con proyectos como Porffor que apuntan a objetivos similares. Scriptc de Vercel afirma lograr esto sin un runtime, pero los escépticos señalan la dificultad de replicar las semánticas de JavaScript de forma nativa y el rápido ritmo de desarrollo del proyecto.

Esta plataforma aborda dos puntos críticos en tinyML: la dificultad de etiquetar manualmente datos de sensores de series temporales y la falta de herramientas de análisis integradas. **Contexto**: TinyML es un campo del aprendizaje automático que se centra en implementar modelos en dispositivos de ultra bajo consumo, como microcontroladores, permitiendo la IA en dispositivos periféricos con recursos limitados.
